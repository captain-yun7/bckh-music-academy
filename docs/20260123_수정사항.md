## 추가된 관리자 기능

### 특별 프로그램 관리 (`/admin/programs`)
- HT 프로그램, 케이크콘서트, 오픈스테이지 등 메인페이지 프로그램 카드 관리
- 프로그램 추가/수정/삭제
- 이미지, 설명, 순서 설정

### 전공 관리 (`/admin/subjects`)
- 메인페이지 커리큘럼 섹션의 전공별 정보 관리
- 설명, 특징 태그 편집
- 공개/비공개 설정

### 메인페이지 연동
- `ProgramsSection`: DB에서 프로그램 데이터 가져오기 (폴백 지원)
- `CoursesSection`: 전공/과정 데이터 API 연동 (폴백 지원)
