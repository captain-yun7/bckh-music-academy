## 메인화면

### 1. 로고와 학원소개 간격
- **상태**: ❓ 확인 필요
- **내용**: "경희실용음악학원 로고와 학원소개 간격이 너무 좁다"
- **질문사항**:
  - "학원소개"가 어떤 섹션을 말하는 것인지?
  - 네비게이션 로고와 히어로 섹션 사이인지, 아니면 다른 곳인지 확인 필요

### 2. 히어로 슬라이드쇼 디자인
- **상태**: ❓ 확인 필요
- **내용**: 초기 디자인을 요청
- **현재 상태**: 이미지만 슬라이드됨 (텍스트/버튼 없음)
- **질문사항**:
  - 어떤 디자인 요소가 필요한지? (텍스트 오버레이, CTA 버튼, 애니메이션 등)
  - 참고할 디자인이 있는지?

### 3. 강사진 노출 순서
- **상태**: ✅ 이미 구현됨
- **현재 동작**: 관리자 페이지에서 설정한 `order` 값 기준으로 정렬 (드래그 앤 드롭으로 순서 변경 가능)
- **코드 위치**: `src/app/api/instructors/route.ts:23`
  ```typescript
  orderBy: [{ order: 'asc' }, { createdAt: 'desc' }],
  ```
- **안내**: 관리자 페이지 > 강사진 관리에서 드래그하여 순서 변경 가능

### 4. 배출뮤지션 제작
- **상태**: ❓ 확인 필요
- **현재 상태**: 이미 배출뮤지션 섹션 및 페이지가 존재함
  - 메인: `src/components/MusiciansSection.tsx`
  - 전체 페이지: `src/app/musicians/page.tsx`
  - 관리자: `src/app/admin/(dashboard)/musicians/page.tsx`
- **질문사항**: 추가로 어떤 작업이 필요한지?

### 5. 수강생혜택 삭제
- **상태**: ❓ 확인 필요
- **내용**: "전공별로 과정별로 다른 부분이라 삭제 부탁"
- **질문사항**:
  - "수강생혜택"이 어떤 섹션을 말하는지?
  - 장학제도(ScholarshipSection)? 특별프로그램(ProgramsSection)?
  - 아니면 커리큘럼 내 혜택 부분?

### 6. 장학혜택 수정
- **상태**: ✅ 수정 가능
- **요청 내용**:
  | 장학 종류 | 대상/조건 | 할인율 |
  |----------|----------|--------|
  | 입학장학 | 재수생 및 반수생, 예비 5번 이내 | 15% ~ 50% (차등지급) |
  | 성적장학 | 학기말 시험 1, 2, 3등 | 20% ~ 50% |
  | 상점장학 | 출석, 수업태도, 연습 성실도에 따른 상점 부여 | 5% ~ 20% |
- **수정 필요 파일**:
  - `src/components/ScholarshipSection.tsx` (메인)
  - `src/app/scholarship/page.tsx` (세부 페이지)

### 7. 하단 전화번호 수정
